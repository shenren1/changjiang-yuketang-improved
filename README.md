## 核心原则

| 原则 | 说明 |
|---|---|
| **AI 理解题目** | 把题干与选项文本发给 AI（DeepSeek / OpenAI 等），由模型推理答案，而不是靠关键词匹配 |
| **正确率优先** | 只用高置信度来源作答；不确定就交给人，不盲目猜测 |
| **安全提交** | 全部题目答完才提交一次，不反复提交 |
| **答案缓存** | 答对过的题自动缓存，同一道题不再重复调用 AI |

## 功能特性

### 🎬 视频

- **自动播放**：进入视频页自动接管播放，默认静音
- **倍速播放**：1.0x ~ 10.0x 共 12 档（1.0 / 1.25 / 1.5 / 1.75 / 2.0 / 2.5 / 3.0 / 4.0 / 5.0 / 6.0 / 8.0 / 10.0），默认 2.0x
- **播完自动跳转**：视频结束后自动进入下一个**未完成**任务（优先同类视频，其次作业/考试）
- **跨章节 / 跨课程**：一门课完成后可自动进入下一门
- **防闪动**：不会在播放/暂停之间来回切换；起播失败按指数退避重试，多次失败后停手等人
- **进度保护**：不做任何“向前拖拽”式跳转（平台会把跳过的片段记为未观看，导致永远不打钩）
- **上报队列看护**：自动清理平台写满的上报队列，避免“播完了却不打钩”
- **覆盖率补播**：读取平台记录的「已观看区间」，只补没看过的片段，而不是从头重放
- **倍速锁定**：播放器反复改写倍速时自动按回面板值（原型级强写 + 事件自愈）

### 📝 答题

- **AI 智能答题**：支持 DeepSeek / OpenAI / Anthropic 及任意 OpenAI 兼容接口
- **8 策略选项提取**：多层级 DOM 解析，兼容 `判断题 对/错`、字母/数字前缀、React/Vue 纯文本选项、全文回退等非标准渲染
- **题型支持**：单选、多选、判断、填空、主观题（简答/论述/计算/分析）
- **多层答题策略**：缓存 → 全局状态 → DOM 数据 → AI 推理 → 手动兜底
- **手动答题辅助**：AI 也无法确定的题目橙色高亮，暂停等待手动选择，选择后自动缓存
- **答案缓存**：正确作答过的题自动入库，命中率随使用提升

### 🧭 导航与界面

- 自动识别左侧目录树，按「视频 → 未完成」优先顺序跳转
- 悬浮控制面板：开始 / 暂停、倍速、静音、自动下一章、跨课程、AI 设置、日志
- 运行日志实时输出，支持通知提醒（`GM_notification`）

## 安装

1. 安装浏览器扩展 **Tampermonkey**
2. 打开 Tampermonkey 管理面板 → **添加新脚本**
3. 清空模板，粘贴 `yuketang-automator.js` 的**完整内容** → `Ctrl+S` 保存
4. 打开并登录 <https://changjiang.yuketang.cn/>

> 更新脚本时同样操作：全选替换内容并保存，然后**刷新课程页面**（已打开的标签页不会自动加载新版本）。

## AI 答题配置

> AI 答题是**可选功能**。不配置也能用，但只能依赖缓存与 DOM 数据，多数题目会转入手动作答。

推荐使用 **DeepSeek**：国内可直接访问、价格低、响应快。

### 快速配置

1. 打开 [DeepSeek 开放平台](https://platform.deepseek.com/)，注册并创建 **API Key**
2. 在脚本面板中展开 **🤖 AI 答题设置**
3. 勾选 **启用AI**
4. 填入 API Key（格式 `sk-xxxxxxxx`）
5. 端点与模型保持默认即可：
   - API 地址：`https://api.deepseek.com/v1/chat/completions`
   - 模型：`deepseek-chat`
6. 点击右侧 **测试** 按钮，确认能连通（会发送一次最小请求）

### 支持的 API

| 服务商 | API 地址 | 模型 |
|---|---|---|
| **DeepSeek**（推荐） | `https://api.deepseek.com/v1/chat/completions` | `deepseek-chat` |
| OpenAI | `https://api.openai.com/v1/chat/completions` | `gpt-4o` / `gpt-4o-mini` |
| Anthropic | `https://api.anthropic.com/v1/messages` | 需适配器（非 OpenAI 兼容格式） |
| 其他兼容服务 | 任意 OpenAI 兼容地址 | 对应模型名 |

> 非 OpenAI 兼容的服务（如原生 Anthropic 接口）需要自行改造 `AIAnswerer._callAPI` 的请求体与解析逻辑。

## 使用

### 基本流程

```
登录平台 → 进入课程 → 配置 AI Key（可选）→ 调整倍速 → 点「开始运行」
        → 视频自动播放 → 遇到视频播完 → 自动跳下一个任务
                       → 遇到试题 → 缓存/DOM 快速作答 → AI 推理 → 手动兜底
```

### 步骤

1. 手动登录 <https://changjiang.yuketang.cn/>，进入课程
2. 配置 AI API Key（见上一节；不配也能跑，但无法 AI 答题）
3. 在面板选择播放倍速（建议 1.0x~2.0x，过高可能被平台限制）
4. 点击 **开始运行**
5. 视频自动播放；遇到试题自动处理
6. AI 也拿不准的题目会**橙色高亮**并暂停，手动选择后点 **✅ 继续运行**（答案会被缓存）

### 面板说明

| 控件 | 作用 |
|---|---|
| ▶ 开始 / ⏸ 暂停 | 启停自动化主循环 |
| 倍速下拉 | 视频播放速度（12 档） |
| 静音 | 是否静音播放（默认开） |
| 自动下一章 | 视频/任务完成后是否自动跳转 |
| 跨课程 | 一门课完成后是否自动进入下一门 |
| 🤖 AI 答题设置 | 启用 AI、API 地址、Key、模型、测试 |
| 🗑 清除缓存 | 清除**当前页面**题目的答案缓存，强制重新作答 |

## 答题策略

| 轮次 | 策略 | 说明 |
|---|---|---|
| 第一轮 | 缓存 → 全局状态 → DOM 数据 | 毫秒级，纯本地完成，命中即作答 |
| 第二轮 | AI 推理 | 逐题调用 API，每题约 1~3 秒 |
| 第三轮 | 手动兜底 | 橙色高亮提示，手动选择后写入缓存 |

> 全部题目答完才提交一次。提交后若平台回显正确答案，脚本会自动抓取并写入缓存。

## 答案缓存

- **自动缓存**：答对/确认过的题目按题干哈希缓存，重复出现时零延迟命中
- **首次使用某课程**时 AI 调用比例高，用久之后命中率会越来越高
- **导出 / 导入**：缓存存放在脚本管理器（Tampermonkey）的脚本存储中，键名 `answerCache`

> ⚠️ **不要在网页控制台里调用 `GM_getValue` / `GM_setValue`** —— 脚本运行在 Tampermonkey 的沙箱环境中，页面控制台访问不到这些 API，会报 `GM_getValue is not defined`。
>
> 正确的做法：Tampermonkey 管理面板 → 找到本脚本 → 打开 **存储 / Storage** 标签页，可直接查看和编辑 `answerCache`、`aiSettings` 等值。
>

## 注意事项

- 必须配置 AI API Key 才能启用 AI 答题，否则只能依赖缓存与 DOM 数据
- AI 每题耗时约 1~3 秒，10 道题约半分钟；题目越多越建议先让缓存积累起来
- **跨域 iframe 中的视频无法控制**（仅支持同源 iframe 内的播放器）
- 倍速过高（≥4x）可能触发平台限制，表现为倍速被改回、进度不计入
- 视频“跑完”后目录里的 ✓ 与完成度百分比**只在刷新或重新进入课程时更新**，运行中卡片不动是正常现象
- 平台侧存在已知缺陷（上报队列写满后静默丢弃事件），脚本已加自动清理，如仍不打钩可手动清理：`localStorage.removeItem('nhd')`

## 故障排查

| 问题 | 排查方向 |
|---|---|
| AI 不工作 | 检查 API Key 是否正确、端点能否访问；点 **测试** 按钮验证 |
| AI 答案错误 | 换模型（如 `deepseek-chat` → `gpt-4o-mini`）；确认题目选项被正确提取（看日志 `选项提取(策略X)`） |
| API 超时 | 检查网络/代理；AI 超时默认 15 秒 |
| 多数题需手动 | 确认已勾选「启用AI」且 Key 已填 |
| 起播时播放/暂停反复闪、控制台刷 `AbortError` | 升级到 3.0.12 及以上 |
| 视频播完不自动跳 | 确认面板「自动下一章」已勾选；目录若改版需更新选择器 |
| 播完目录不打钩、完成度不涨 | 刷新页面后确认；平台 `nhd` 队列问题，3.0.12 起自动处理 |
| 完成度卡在 80~90% 上不去 | 3.0.13 已把“整条清空队列”改为“删旧保新”；若仍卡住，多为该视频确实有片段未覆盖 |
| 面板改了倍速、实际速度没变 | 3.0.18 起会自动强写并打印 `倍速被改成 …x，已强制改回 …x`；仍无效就把这几行日志发我 |
| 视频播完但覆盖率/完成度不涨 | 3.0.16 起按「已观看区间」只补缺口；可在视频右上「完成度 → 详情」查看蓝色/灰色分段确认 |
| 已完成却还在傻播同一个视频 | 3.0.19 已修（补播结束封口 + 目录打钩即跳）；若仍出现，把补播那几行日志发我 |
| 运行中进度条、完成度不动 | 正常现象，这两个数字只在进入课程/刷新时重新拉取 |
| 视频停在最后一帧不动 | 脚本会自动回退重播或跳过；仍卡住可手动点一次播放 |
| 面板没出现 | 确认脚本已启用、URL 在 `@match` 范围内，刷新页面 |
